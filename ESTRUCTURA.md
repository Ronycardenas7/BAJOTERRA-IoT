# Estructura del proyecto

| Carpeta | Contenido |
|---|---|
| `web_pwa/` | Web React y Vite. `src/` contiene la interfaz, el cliente Supabase y las funciones de sesión, telemetría y actuadores. `public/` contiene los recursos estáticos. |
| `firmware/` | Código de los nodos ESP-NOW, el ESP32 Maestro y la pantalla táctil CYD. |
| `supabase/` | Migraciones SQL del proyecto. |
| `docs/` | Guías de hardware, arquitectura y registro de decisiones. |

La configuración y los comandos de Vercel están en el [README](README.md#despliegue-en-vercel).
